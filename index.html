Persyaratan browser

Untuk mencoba Gemini Nano langsung di perangkat, gunakan Chrome desktop yang terbaru. Ketersediaan AI lokal ditentukan juga oleh sistem operasi, perangkat keras, ruang penyimpanan, dan API yang dipakai tiap aplikasi.

Chrome · Desktop
Memeriksa Chrome On-device AI…

Memeriksa dukungan browser dan status model lokal.

Browser & sistem operasi

Google Chrome versi terbaru di Windows 10/11, macOS 13+, Linux, atau Chromebook Plus yang kompatibel. Fitur model bahasa bawaan ini belum didukung di Chrome Android/iOS.

Perangkat & penyimpanan

Untuk model bahasa bawaan Chrome: CPU 4 inti dengan RAM 16 GB atau GPU dengan VRAM lebih dari 4 GB, serta minimal 22 GB ruang kosong di drive profil Chrome. Persyaratan dapat berubah mengikuti versi model.

Unduh model pertama kali

Chrome perlu mengunduh model sebelum digunakan. Sediakan koneksi internet tanpa batasan kuota; setelah siap, pemrosesan Gemini Nano berlangsung di perangkat.

Buka lewat launcher server

Jangan buka file langsung dengan file://. Klik ganda jalankanserver.command untuk menjalankan HTTPS pada https://localhost:1234 agar API On-Device aktif dalam Secure Context.

Cara mengaktifkan Gemini Nano di Chrome

Beberapa halaman di playground ini memakai API Chrome eksperimental. Nama atau ketersediaan flags bisa berbeda menurut versi Chrome.

  1. Perbarui Chrome desktop, lalu buka chrome://flags.
  2. Cari Optimization Guide On Device Model dan pilih Enabled BypassPerfRequirement; cari Prompt API for Gemini Nano dan pilih Enabled. Jika memakai fitur LiteRT-LM/WebGPU, aktifkan juga Enables WebGPU bila opsinya tersedia.
  3. Pilih Relaunch untuk memulai ulang Chrome.
  4. Buka chrome://components, cari Optimization Guide On Device Model, lalu pilih Check for update. Tunggu model selesai diunduh.
  5. Kembali ke playground melalui alamat localhost. Jika belum terdeteksi, cek chrome://on-device-internals dan pastikan perangkat memenuhi persyaratan.

Flags bersifat eksperimental dan dapat dihapus atau berubah. Jika opsinya tidak tersedia, cek dokumentasi Chrome untuk cara aktivasi API yang berlaku pada versi Anda. Lihat persyaratan resmi Chrome dan status Prompt API.

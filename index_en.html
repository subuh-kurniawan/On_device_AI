Understanding Chrome On-Device AI

How Gemini Nano runs natively inside your browser, computes directly on local hardware, and guarantees absolute privacy.

Next-Gen Web AI
⚡

How Does It Work?

Unlike cloud-based AI that transmits your prompts to remote datacenters thousands of miles away, Chrome On-Device AI executes the Gemini Nano foundation model directly inside your device's memory. Chrome harnesses local hardware acceleration (NPUs, GPUs via WebGPU, or multi-core CPUs) for zero-latency inference.

🛡️

Zero Data Leakage & Absolute Privacy

Because all inference executes strictly offline, confidential information such as financial records, legal contracts, medical data, and proprietary code never leaves your machine. Zero risk of data breach, zero telemetry tracking, and your inputs are never used to train public models.

💡

Zero Token Costs & No API Subscriptions

Say goodbye to costly third-party API tokens (OpenAI/Anthropic), monthly subscriptions, and annoying rate-limiting quotas. Even when you are completely offline on a flight or in remote areas, your local AI playground continues to function at full capacity.

🌐

Standardized Web Platform APIs

Google integrates a comprehensive suite of native web APIs callable straight from JavaScript: Prompt API (conversations & reasoning), Summarization API (document digests), and Translation API (instant multilingual on-device translation).

Lightweight, Quantized & Battery Efficient

Chrome's Gemini Nano is heavily optimized and quantized (4-bit / 8-bit), consuming only ~1.5 to 2.2 GB of disk space. It downloads once via the Chrome Component Updater and activates only on demand, ensuring minimal battery impact on modern laptops.

Browser Requirements

To experience Gemini Nano on-device, use the latest desktop Chrome. Local AI availability also depends on your operating system, hardware specs, disk space, and the APIs used by each application.

Browser & Operating System

Latest Google Chrome on Windows 10/11, macOS 13+, Linux, or compatible Chromebook Plus. Chrome built-in models are not supported on mobile (Android/iOS).

Hardware & Storage

For Chrome built-in models: 4-core CPU with 16 GB RAM or GPU with >4 GB VRAM, plus at least 22 GB free disk space on the profile partition. Requirements may change across model versions.

Initial Model Download

Chrome downloads model weights before initial execution. An unmetered internet connection is required; once downloaded, Gemini Nano runs completely offline.

Run via Local Server

Do not open files directly via file://. Double-click jalankanserver.command or run via HTTPS so On-Device APIs function in a Secure Context.

How to Enable Gemini Nano in Chrome

Some pages in this playground use experimental Chrome APIs. Flag names or availability may vary across Chrome versions.

  1. Update desktop Chrome, then open chrome://flags.
  2. Search for Optimization Guide On Device Model and select Enabled BypassPerfRequirement; search for Prompt API for Gemini Nano and select Enabled. If using LiteRT-LM/WebGPU, also enable Enables WebGPU if available.
  3. Select Relaunch to restart Chrome.
  4. Open chrome://components, locate Optimization Guide On Device Model, and select Check for update. Wait for download to finish.
  5. Return to the playground via localhost. If not detected yet, check chrome://on-device-internals and verify requirements.

Flags are experimental and may change or be removed. If an option is unavailable, check official Chrome documentation for activation guidelines applicable to your version. See official Chrome requirements and Prompt API status.
